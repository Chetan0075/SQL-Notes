# SQL E-Commerce Analytics Project

## Overview

This project simulates a real-world e-commerce database and demonstrates SQL concepts ranging from database design to advanced analytics.

The project was built to strengthen practical SQL skills used in analytics, reporting, and enterprise environments.

---

## Objectives

* Design a relational database from scratch
* Understand primary and foreign key relationships
* Perform data analysis using SQL
* Build reusable reporting objects using Views and Stored Procedures
* Implement indexing for query optimization
* Apply data cleaning and duplicate handling techniques
* Generate business insights from transactional data

---

## Database Schema

### Customers

Stores customer information.

### Orders

Stores order-level transactions.

### Order Details

Stores products purchased within each order.

### Products

Stores product catalog information.
